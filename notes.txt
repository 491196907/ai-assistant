【笔记编号】PY-W2-007。本笔记是「AI 学习计划」第 1–2 周的 Python 知识汇总，最后更新于 2026 年 9 月。整理者代号：yaoyi。

【变量与输出】变量就像贴标签的盒子，name = "小明" 就是把「小明」放进 name 这个盒子。print() 让电脑把话说出来。f-string 写法是 f"你好，{name}"，大括号里的变量会被替换成它的值。

【输入 input】input("提示") 会暂停程序等用户输入，返回的永远是字符串。想算数必须先转换：int("5") 得到整数 5，float("3.14") 得到小数 3.14。字符串 "3" + "5" 结果是 "35"（拼接），而 3 + 5 才是 8。

【类型转换】常用转换函数有三个：int() 转整数、float() 转小数、str() 转字符串。如果输入的不是数字却用 int()，会抛出 ValueError。

【条件判断】if / elif / else 用来做分支。条件后面必须写冒号，下一行必须缩进 4 个空格。比较运算符有 == != > < >= <=。注意 = 是赋值，== 才是比较。Python 支持链式比较，例如 60 <= score < 90。

【循环】for i in range(5) 会循环 5 次，i 依次取 0 到 4。range(1, 6) 取 1 到 5，是左闭右开区间。while 循环只要条件为真就一直执行，必须让条件逐渐变假，否则会死循环。total += i 是累加的常用写法。

【函数】用 def 定义函数，例如 def add(a, b): return a + b。return 把结果交回给调用处；如果没有写 return，函数返回 None。print 是给屏幕看的，return 是给代码用的。入口写法是 if __name__ == "__main__": main()。

【列表 list】列表用方括号定义，例如 scores = [75, 90, 50]。下标从 0 开始，scores[0] 是第一个，scores[-1] 是最后一个。len() 取个数，append() 在末尾追加，sum() max() min() 分别求和、取最大、取最小。for s in scores 可以遍历所有元素。

【字典 dict】字典用大括号定义，存的是键值对，例如 scores = {"小明": 90, "小红": 75}。用键取值：scores["小明"] 得到 90。如果键不存在会报 KeyError，所以推荐用 scores.get("小李", "查无此人") 安全取值。用 scores.items() 遍历时可以同时拿到键和值。max(scores, key=scores.get) 可以取出分数最高的那个人名。

【文件读写】用 with open("文件名", 模式, encoding="utf-8") as f 打开文件，with 会自动关闭文件。模式有三种：w 写入（会清空原内容）、r 读取、a 追加。write() 不会自动换行，必须自己写 \n。读取时可以用 f.read() 读全部，或者 for line in f 逐行读。

【字符串处理】line.strip() 去掉首尾空白和换行符。line.split(",") 按逗号把字符串切成列表。name, score = line.strip().split(",") 这个写法叫解包，会把列表元素按顺序分别赋给变量，左边变量个数必须和右边元素个数一致。

【异常处理】用 try / except 接住错误，让程序不崩溃。常见错误类型：ValueError（转换失败）、ZeroDivisionError（除以零）、FileNotFoundError（文件不存在）、KeyError（字典没这个键）、IndexError（列表下标越界）。尽量写具体的错误类型，不要写光秃秃的 except。

【JSON】JSON 是一种文本数据格式，长得像 Python 的字典。四个函数要分清：json.loads(字符串) 把字符串转字典，json.dumps(字典) 把字典转字符串，json.load(文件) 从文件读，json.dump(字典, 文件) 写入文件。结尾带 s 的用于字符串。保存时加 ensure_ascii=False 才能正常显示中文，indent=2 可以美化缩进。

【调用大模型 API】调用大模型需要三个东西：API Key（身份证明）、URL（接口地址）、请求体。请求头里放 Authorization: Bearer 加 Key。请求体是一个字典，包含 model（模型名）和 messages（消息列表）。messages 里每条消息是一个字典，role 可以是 system（设定人设）、user（用户提问）、assistant（模型回答）。回答要从 data["choices"][0]["message"]["content"] 里一层层取出来。

【多轮对话】大模型本身没有记忆。要做到"记得上文"，必须把之前的对话历史一起发过去：每一轮把用户输入和模型回答都 append 进 messages 列表。因为每轮都要重发全部历史，所以对话越长，消耗的 token 越多，费用也越高。

【Agent 与工具调用】Agent 的本质是一个循环：模型思考 → 决定调用某个工具 → 拿到结果 → 再思考 → 给出回答。工具就是你事先写好的 Python 函数。模型自己不能运行代码，它只能"说"要调用哪个函数、参数是什么，真正执行的是你的程序。通常用字典把函数存起来，例如 tools = {"add": add}。

【RAG 检索增强】RAG 的流程是：把资料切成小块（chunk），用户提问时先检索出最相关的几块，只把这几块连同问题一起发给模型，让它基于资料回答。这样做既能突破 token 上限，又更省钱，还能减少幻觉。提示词里要明确要求"只根据资料回答，资料里没有就说没有"。

【学习建议】代码不是背出来的，而是查出来、写出来的。遇到不会的语法，查速查表即可。卡住时用四步法：读需求、拆步骤、翻译成代码、运行调试。
